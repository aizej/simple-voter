# Simple Voter

A lightweight server side Python utility for ideas that can be voted on by anyone.
Anyone can add ideas, vote on ideas and everything updates in real-time.
Every vote is stored in sqlite database and multiple distinct idea tables are supported.


## Purpose

This project is a simple script for interacting with the voting page at:
http://158.101.167.252/main/welcome-to-my-portfolio/web-utilities/idea-voting/

It is intended to be easy to run, easy to understand, and useful for basic voting on features and ideas.

## Usage

1. Open the script.
2. Adjust the vote details if needed.
3. Run it with Python.
4. Connect with frontend app.
