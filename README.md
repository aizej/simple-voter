# Simple Voter

A lightweight Python utility for submitting quick votes to the idea voting system on my website.

## Purpose

This project is a simple script for interacting with the voting page at:
http://158.101.167.252/main/welcome-to-my-portfolio/web-utilities/idea-voting/

It is intended to be easy to run, easy to understand, and useful for basic voting automation or testing.

## Usage

1. Open the script.
2. Adjust the vote details if needed.
3. Run it with Python.
